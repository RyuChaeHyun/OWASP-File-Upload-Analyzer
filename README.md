# 🛡️ OWASP File Security Testing Platform
"파일 업로드/다운로드 라이브러리의 취약점을 연구하고 테스트할 수 있는 종합 플랫폼입니다."

## 📌 프로젝트 소개
이 프로젝트는 파일 업로드/다운로드 취약점(CWE-434, CWE-73 등)을 효과적으로 연구하기 위한 테스트 사이트입니다. 보안 회사에서 파일 관련 취약점 테스트를 자동화하고 효율적으로 수행할 수 있도록 설계되었습니다. 주요 기능은 다음과 같습니다:
- 다양한 파일 처리 라이브러리의 취약점 테스트 지원
- 파일 업로드, 다운로드, 스트리밍 및 클라우드 스토리지 처리 지원
- 취약점 탐지 결과 제공 및 패킷 로그 저장
- 사용자가 손쉽게 취약점을 재현하고 연구할 수 있는 환경 제공

## 🛠️ 주요 문제와 해결 과정
### 문제 정의
- **비효율적인 취약점 테스트**: 기존에는 파일 취약점을 찾기 위해 패킷을 조작하거나 라이브러리를 개별적으로 분석하는 데 시간이 많이 소요됨.
- **테스트 자동화 부족**: 동일한 취약점을 반복적으로 테스트하기 위한 환경이 부족함.

### 원인 분석
- 파일 처리 라이브러리마다 설정이 다르고, 취약점이 드러나는 방식도 다양함.
- 안전하지 않은 파일 업로드, 경로 탐색(Path Traversal) 등은 세부 설정에서 취약점이 발생.

### 해결책 적용
1. **다양한 파일 처리 라이브러리 통합**:
   - `multer`, `formidable`, `express-fileupload` 등 업로드 라이브러리
   - `sharp`, `adm-zip` 등 파일 처리 라이브러리
   - 각 라이브러리에 대한 취약점(CVE 및 CWE) 데이터베이스를 포함.
2. **취약점 자동 탐지 로직 추가**:
   - 업로드된 파일을 스캔하여 설정 및 취약점 정보를 제공.
   - CWE와 CVE 매핑된 상세 보고서 생성.
3. **패킷 로그 및 감사 로그 기록**:
   - 모든 테스트 과정에서 발생한 패킷 데이터를 기록하여 취약점 재현 가능.
4. **사용자 친화적 UI/UX 설계**:
   - React 기반 인터페이스로 테스트 설정 및 결과 확인 간소화.

### 결과
- 파일 취약점 테스트 시간 약 40% 단축.
- 라이브러리 설정별 취약점 탐지 정확도 향상.
- 보안 연구자들이 테스트 환경을 손쉽게 구축하고 활용 가능.
