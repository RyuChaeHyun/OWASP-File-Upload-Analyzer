# 🛡️ OWASP File Security Testing Platform
"총 12종의 파일 업로드/다운로드 라이브러리의 취약점을 **심층 연구**하고 **테스트**할 수 있는 **보안 전문가**를 위해 제작된 종합 테스트 플랫폼"
<br>

> 🔄 본 플랫폼은 새로운 라이브러리나 버전이 출시될 때마다 즉시 테스트 환경에 추가할 수 있도록 설계되었습니다.
>
> 📅 **최근 업데이트**: 2024.01.13 - Multer v1.4.5-lts.1 취약점 테스트 환경 추가

## 📌 프로젝트 개요
이 프로젝트는 **OWASP Top 10** 에 선정된 주요 취약점 중 **파일 업로드/다운로드** 취약점(주요정보통신기반시설 WEB-22, WEB-23)을 **효과적으로 연구하기 위한 테스트 사이트**입니다.

## 🤔 왜 이 프로젝트를 시작하게 되었나요?
보안 회사 근무 시절, 개발 경험을 보유한 직원으로서 **파일 업로드/다운로드 취약점 테스트 과정의 비효율성**을 목격했습니다. 보안 전문가들이 **매번 수동으로 파일을 조작**하고, 패킷을 분석하며, 각 라이브러리마다 설정을 변경하는 과정에서 많은 시간이 소요되는 것을 확인했습니다. 특히, OWASP Top 10에 선정된 중요한 취약점임에도 **체계적인 테스트 도구가 부재**하여 동료들이 많은 시간을 소모하고 있었습니다.

<br>

> 🥸 : "파일 취약점 테스트에 소요되는 시간의 80%가 환경 설정과 패킷 분석에 사용되고 있습니다." - *보안 기술팀 내부 리서치 결과* -

> 💁‍♀️ : "파일 라이브러리 자체의 취약점을 제대로 파고들고 싶은데, 실서비스에 영향을 줄까 봐 마음껏 테스트도 못하고 있어요." - *보안팀 취약점 분석 담당자* -


이러한 현장의 문제를 해결할 방법을 고민하던 중, 동료들의 시간을 절약할 수 있는 도구를 만들면 좋겠다는 생각이 들었습니다. 따라서 개발 경험을 살려, **파일 처리 라이브러리의 취약점 테스트 자동화**와 더불어 **라이브러리 자체의 보안 취약점을 심층 분석**할 수 있는 통합 테스트 플랫폼을 개발하게 되었습니다. 이를 통해 보안 전문가들이 반복적인 테스트 업무에서 벗어나 더 본질적인 취약점 연구와 분석에 집중할 수 있기를 바랐습니다.

<br>

## 🌍 주요 목표

**🎯 주요 목표 1: 취약점 테스트 자동화**
- 수동 테스트 과정의 자동화(**파일 확장자 변경, MIME 타입 조작 등 번거로운 수동 작업을 클릭 한 번으로**)
- 테스트 시간 및 리소스 절감(30분 걸리던 환경 설정과 **패킷 분석이 5분 내로**)
- 체계적인 테스트 프로세스 확립

<br>

**🔬 주요 목표 2: 심층 취약점 분석**
- 실제 **운영 환경에 영향 없는** 안전한 테스트(**실제 서비스 영향 걱정 없이** 마음껏 테스트 가능)
- 파일 처리 라이브러리 자체의 취약점 분석(**보안전문가들은 개발 경험이 없어** 라이브러리 자체의 취약점 점검을 위한 환경 세팅이 어려움)
- 버전별/설정별 취약점 영향도 검증(라이브러리의 **모든 설정과 버전**에 따른 심층 분석)

## 🚀 설치 및 실행 방법

### 1️⃣ 필수 프로그램 설치

#### 1. Git 설치
운영체제에 맞는 명령어로 Git을 설치해주세요.

**Windows**
```bash
# Windows의 경우 아래 설치 경로를 입력하면 자동 설치됩니다
http://git-scm.com/download/win
```

**Mac**
```bash
# Mac의 경우 Homebrew를 통해 설치해주세요
brew install git
```

**Linux (Ubuntu/Debian)**
```bash
sudo apt-get update
sudo apt-get install git
```

버전 확인:
```bash
git --version
```

<hr>

#### 2. Node.js 설치 및 버전 확인
- [Node.js](https://nodejs.org/) 설치 (v20.16.0 또는 v20.18.0)
- npm v10.8.1 (Node 설치 시 자동으로 설치됨)

현재 버전 확인:
```bash
node -v
npm -v
```

> 💡 **다른 Node 버전을 사용 중이신가요?**
> nvm(Node Version Manager)을 통해 버전 변경이 가능합니다:
> ```bash
> nvm install 20.18.0  # 필요한 버전 설치
> nvm use 20.18.0      # 해당 버전으로 전환
> ```

<br>

### 2️⃣ 프로젝트 설치 및 실행

1. **코드 다운로드**
```bash
# 프로젝트 다운로드
git clone https://github.com/RyuChaeHyun/OWASP-File-Upload-Analyzer.git

# 프로젝트 폴더로 이동
cd file-security-platform
```

2. **패키지 설치 및 실행**
```bash
# 필요한 패키지 설치
npm install

# 프로그램 실행
npm start
```

3. **플랫폼 접속**
- 웹 브라우저에서 [http://localhost:3000](http://localhost:3000) 접속
- 자동으로 브라우저가 열리지 않는 경우 위 주소를 직접 입력해주세요

<br>

> 🚨 **문제 해결**
> - Node 버전 불일치: 위의 nvm 명령어로 버전을 맞춰주세요
> - 실행 오류 발생 시: 3000번 포트 사용 여부를 확인해주세요
> - npm 관련 오류: `npm cache clean --force` 실행 후 다시 시도해보세요
> - Git 설치 문제: 각 운영체제의 패키지 매니저(chocolatey, brew, apt)가 설치되어 있는지 확인해주세요
>
